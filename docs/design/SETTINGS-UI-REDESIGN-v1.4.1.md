# Musefold 设置界面 v1.4.1

本说明记录已落地的设置界面结构。视觉规格以
`docs/design/settings-ui-prototype-v1.4.1.html` 为准，功能范围以当前源码和测试为准。

## 目标

- 设置页作为独立工作区占满窗口，不显示产品侧栏、产品标题栏和全局顶部入口。
- 桌面端和 Web 端共用设置工作区、卡片、设置行、分段控件和开关。
- 桌面端保留现有设置能力；Web 端只展示当前可用的账户与已连接应用能力。
- 不新增没有数据接入或持久化实现的占位设置。

## 组件归属

共享组件位于 `packages/product-ui/src/settings`：

- `SettingsWorkspace`：侧栏导航、搜索、窄屏标签栏和内容面板。
- `SettingsSection`：页面标题、说明和页面级操作。
- `SettingsCard`：相关设置项的容器。
- `SettingsRow`：标签、说明和控件的标准行。
- `SettingsSegmentedControl`：互斥枚举选择。
- `SettingsSwitch`：布尔设置。

桌面端 `SectionShell`、`SettingRow` 和 `ChoiceChips` 只保留薄适配，视觉和交互实现不再复制。

## 布局规格

| 区域 | 规格 |
| --- | --- |
| 设置侧栏 | 固定 `240px`，右侧 `1px` 分隔线 |
| 内容外边距 | 宽屏 `28px 32px`，窄屏 `24px 20px` |
| 内容最大宽度 | `896px`，水平居中 |
| 页面标题 | `24px / 600` |
| 卡片间距 | `16px` |
| 卡片头部 | `16px` |
| 设置行 | 两列 `minmax(0, 1fr) minmax(192px, 288px)`，块向间距由密度 token 驱动，左右 `16px` |
| 响应式切换 | 小于 `960px` 时隐藏侧栏，显示返回/搜索工具栏与横向标签栏；小于 `640px` 时设置行改为单列 |

桌面无标题栏状态保留 `32px` 可拖拽区。窄屏工具栏在该区域下方开始，不让返回或搜索控件
落入拖拽层。macOS 使用原生窗口按钮；Windows 和 Linux 仅浮动显示窗口控制，不生成完整的
产品顶部栏。

## 圆角规则

圆角只表达层级和控件类型：

| 元素 | 圆角 |
| --- | --- |
| 设置卡片 | `12px` |
| 搜索、输入、下拉、按钮、导航选中态 | `6px` |
| 分段控件外框 | `6px` |
| 分段控件选项 | `4px` |
| 状态徽标 | `4px` |
| 开关轨道、头像、状态点 | 圆形或胶囊形 |

普通按钮、输入框和导航项不得使用胶囊圆角。头像、状态点和开关等具有明确圆形语义的元素除外。

## 颜色

设置工作区使用原型中的局部 token，避免被双端宿主主题覆盖：

- 浅色背景：`#f6f6f4`；侧栏：`#f1f1ee`；卡片：`#ffffff`。
- 深色背景：`#1a1a1c`；侧栏：`#222224`；卡片：`#2a2a2c`。
- 强调色：`#d6653f`；悬停：`#bc5535`。
- 深浅色边框、文字和交互色与原型 token 保持一致。

## 当前功能范围

桌面设置导航直接映射现有实现：

- 账户与接入：访问模式、豆包网页、Musefold 账号、已连接应用。
- 模型与生成：模型服务、AI 连接、生成默认值。
- 工作区：外观、数据与备份、自动化、已归档对话。
- 支持：关于。

Web 设置保留当前已经具备云端数据接入的内容：

- Musefold 账号。
- 已连接应用。

终端、浏览器、插件、索引、代码主题等参考产品中的设置不属于当前功能，不在 v1.4.1 中展示。

## 验证

- 共享组件单测覆盖导航过滤、选中状态、窄屏工具栏和基础控件语义。
- Electron E2E 固定无标题栏、`240px` 侧栏、`896px` 内容宽度、`12px` 卡片圆角、两列控件轨道和窄屏切换。
- 共享视觉测试比较桌面与 Web 的账户和连接应用内容。
- 交付门禁按根目录 `AGENTS.md` 的命令矩阵执行。
