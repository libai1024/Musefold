# 01. 应用外壳与工作区

## 1. 外壳总图

ZCode 的工作区不是一个全屏路由页面，而是稳定的三栏 Shell。左栏负责“我在哪里、有哪些任务”，中央负责“当前任务进行到哪一步”，右栏负责“任务所需的上下文”。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ macOS / Electron window safe area                                             │
├───────────────┬───────────────────────────────────────────┬─────────────────┤
│ workspace     │ MainView                                  │ context dock    │
│ sidebar       │ task header                               │ tabs            │
│               │ message stream                            │ files / terminal│
│ workspace     │                                           │ changes / ...   │
│ controls      │ Composer                                  │                 │
└───────────────┴───────────────────────────────────────────┴─────────────────┘
```

观察窗口约为 1208 x 766 px：左侧栏约 255 px，右侧面板约 230-265 px，中央区域占据剩余宽度。左栏和右栏均为 dock；中央区域使用 flex 剩余空间。窗口变窄时，优先保护中央任务流和 Composer 的可读性，左右面板可以收窄或收起。

## 2. 左侧栏区域分层

### 2.1 顶部工作区工具行

从上到下可以识别出以下元素：

| 区域 | 控件 | 类型 | 作用 |
| --- | --- | --- | --- |
| 左上 | 工作区图标/名称 | 工作区入口 | 打开工作区相关菜单或标识当前工作区 |
| 左上邻侧 | 后退 | 图标按钮 | 回到上一个任务或页面 |
| 左上邻侧 | 前进 | 图标按钮 | 前往下一个任务或页面 |
| 顶部动作 | 绿色快速动作按钮 | 图标/强调按钮 | 进入创建或快捷操作流 |
| 动作列表 | 新建任务 | 文本+快捷键 | 创建任务，快捷键 `Cmd/Ctrl + N` |
| 动作列表 | 搜索 | 文本+快捷键 | 打开全局搜索/命令中心，快捷键 `Cmd/Ctrl + K` |
| 动作列表 | 自动化 | 文本入口 | 进入自动化相关工作流 |
| 动作列表 | 插件市场 | 文本入口 | 浏览可安装插件 |

按钮尺寸整体偏紧凑，图标按钮依赖 hover 和 tooltip 提供含义；带有明确工作流的入口使用图标加文字。动作列表之间保持短垂直间距，避免把左栏顶部变成一组大卡片。

### 2.2 分组/项目切换条

项目视图顶部有一个 segmented control：

- `分组`：以分组为一级组织结构，任务在分组下展开。
- `项目`：以项目为一级组织结构，项目下继续显示分支和任务。

同一条区域还包含：

- `收起全部`：折叠当前层级中的展开节点。
- `筛选和排序`：打开筛选、排序和视图规则菜单。
- `归档`：进入归档任务或切换归档状态视图。
- 添加项目：创建或接入项目。

学习重点是“主视图切换”和“结构操作”处于同一水平工具条，但它们的视觉权重不同：分组/项目是持续选择状态，收起、筛选、归档是次级动作，添加项目是可见的创建入口。

### 2.3 项目树

项目模式下，每一个项目行至少包含：

| 元素 | 默认状态 | 交互状态 |
| --- | --- | --- |
| 展开箭头 | 指示项目是否展开 | 点击切换子项可见性 |
| 项目图标 | 识别项目类型 | 随 hover 或选中显示更强对比 |
| 项目名称 | 主文本 | 当前项目或当前任务路径高亮 |
| 任务计数/补充信息 | 次文本或右侧信息 | 不抢占项目名称的视觉焦点 |
| 更多 | 通常隐藏 | hover 显示菜单 |

项目展开后，分支或任务使用缩进表达父子关系。缩进应由固定层级 token 计算，不应依赖文字长度。项目行和任务行的行高保持稳定，使鼠标移动时列表不抖动。

项目行的更多菜单包含以下观察到的动作：

- `新建任务`：在该项目上下文中创建任务。
- `查看文件`：打开项目文件或文件浏览上下文。
- 其他项目管理动作：通过更多菜单承载，避免常驻按钮过多。

### 2.4 任务行

任务行显示任务标题与时间/状态摘要。默认状态下信息密度较高，只有当前任务保留明显选中背景。hover 时显示右侧动作：

- `置顶任务`：固定任务在列表上方。
- `归档任务`：从活跃列表移入归档。
- 更多：提供额外的任务级动作。

任务行是最重要的高频重复项，设计上要满足：

1. 标题超过可用宽度时省略，不撑大左栏。
2. hover 动作覆盖摘要区域前，要给动作预留稳定宽度。
3. selected、hover、focus 三种状态不能只靠同一种灰色区分。
4. 归档和危险动作不能与打开任务的主点击区域混在一起。

### 2.5 分组模式

分组视图把任务从项目层级中抽出来，以平面列表展示可拖拽任务。它提供：

- 分组标题和折叠状态。
- 分组内的任务行。
- 新建分组入口。
- 任务拖拽排序或移动的视觉反馈。

分组模式适合快速整理任务；项目模式适合按代码仓库理解上下文。两种模式共用任务行组件，但父级标题、缩进和拖拽目标不同。

## 3. 左栏底部入口

左栏底部是全局设置与连接状态的低频区域：

| 控件 | 形式 | 打开结果 |
| --- | --- | --- |
| 连接使用 | 状态入口/按钮 | 打开主题、缩放、语言、使用统计、升级和连接使用菜单 |
| 移动端远程 | 图标或文本入口 | 进入移动端/远程访问相关功能 |
| 设置 | 齿轮图标按钮 | 进入设置 Shell |
| 侧栏宽度分隔条 | 竖向 splitter | 拖拽调整左栏宽度 |

底部入口不应与任务列表同一滚动容器。任务列表滚动时，设置和连接状态仍然固定在底部。

## 4. 连接使用菜单

点击左下角连接使用入口后，出现局部 popover。菜单项目为：

- `界面主题`：二级菜单，选择系统、浅色、深色或当前可用主题。
- `界面缩放`：二级菜单，调整整体界面缩放比例。
- `界面语言`：二级菜单，选择中文、英文等语言。
- `使用统计`：导航到使用量页面。
- `升级`：进入升级或订阅流程。
- `连接使用`：查看连接、配额或账户相关信息。

这是典型的“账户/应用级菜单”，不要将它与项目级菜单混合。菜单本身不应让 MainView 重新布局，通常使用按钮锚点定位。

## 5. 全局搜索/命令中心

点击左栏 `搜索` 或按 `Cmd/Ctrl + K` 后，显示全局命令中心：

```text
         dim + blur backdrop
                 ┌──────────────────────────────┐
                 │ 搜索输入框                     │
                 │ 全部 | 操作 | 任务 | 文件      │
                 ├──────────────────────────────┤
                 │ 最近任务                       │
                 │ 建议                           │
                 │ 面板                           │
                 │ 配置                           │
                 │ 应用                           │
                 └──────────────────────────────┘
```

观察到的布局特征：

- 遮罩覆盖整个工作区，并有明显的暗化/模糊，使用户把注意力集中到搜索框。
- 面板居中，宽度约 490 px，圆角和阴影比普通 popover 更强。
- 顶部先是输入框，再是分类 tabs。
- 结果按“最近任务、建议、面板、配置、应用”分组。
- 结果行右侧显示快捷键或动作提示。
- 搜索面板支持键盘导航，鼠标 hover 只改变当前结果背景。

它与右侧标签搜索不同：全局搜索负责跨实体动作和导航，右侧搜索只负责上下文标签。

## 6. 工作区选择器

项目按钮或 Composer 中的项目 pill 打开项目选择 popover。菜单包含：

- 搜索工作区输入框。
- 最近或可用工作区列表。
- `kimi-code-usage-query-plugin` 等其他可用项目。
- 当前项目 `Musefold`。
- `打开文件夹`：调用系统文件选择器。
- `远程连接`：进入远程项目连接流程。
- `不在项目中工作`：取消项目上下文。

项目选择器要把当前值放在触发按钮上，并在列表中使用 check 或选中背景。打开文件夹和远程连接属于创建上下文，不应和普通项目项使用完全相同的行语义。

## 7. 分支选择器

分支 pill 打开后包含：

- `搜索分支` 输入框。
- 当前 `main` 分支。
- 当前分支状态，例如 `未提交的更改：1 个文件`。
- `创建并检出新分支...`。
- `Git 图谱`。

分支是任务上下文的一部分，显示当前分支和工作树状态；因此分支选择器不只是一份字符串列表，还必须展示 dirty 状态、创建动作和图谱入口。

## 8. 页面切换与滚动规则

- 左侧栏的项目/任务列表独立滚动；顶部操作和底部全局入口固定。
- MainView 的消息流独立滚动；任务头和 Composer 可固定。
- 右侧面板内部独立滚动，tab 工具条固定在面板顶部。
- 设置页的左侧设置导航固定，右侧设置内容独立滚动。
- Popover 通过锚点定位，不改变三栏宽度。
- 搜索中心和引导属于顶层 overlay；出现时焦点和键盘操作优先交给 overlay。

## 9. 外壳复刻清单

- [ ] 左栏固定宽度、可拖拽调整、可折叠。
- [ ] 项目/分组 segmented control 有明确 selected 状态。
- [ ] 项目、分组、任务的层级缩进稳定。
- [ ] 任务 hover 后按钮出现但不造成行高变化。
- [ ] 左栏底部入口不随任务列表滚动。
- [ ] 全局搜索有全屏遮罩，普通 popover 没有遮罩。
- [ ] 项目和分支选择器能显示当前值及状态摘要。
- [ ] 所有高频图标按钮具备 tooltip、focus ring 和可访问名称。
