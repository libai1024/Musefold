# 03. 设置区全页面与按钮

## 1. 设置 Shell

设置区沿用 ZCode 的暗色应用外壳，但把中央工作区替换成“设置导航 + 设置内容”的双栏结构：

```text
┌────────────────┬──────────────────────────────────────────────┐
│ 返回工作区      │ 页面标题                                       │
│ 基础设置        │ 标题说明                                       │
│   常规          │                                                │
│   外观          │ ┌──────────────────────────────────────────┐ │
│   模型设置      │ │ section title                            │ │
│   浏览器        │ │ dark settings card                      │ │
│ Agent 能力      │ │ label / description       control        │ │
│   记忆          │ └──────────────────────────────────────────┘ │
│   子智能体      │                                                │
│   插件          │ 内容区独立滚动                                 │
│   MCP 服务器    │                                                │
│   技能          │                                                │
│   命令          │                                                │
│   钩子          │                                                │
│ 数据与统计      │                                                │
│   索引库        │                                                │
│   使用统计      │                                                │
│   引导          │                                                │
└────────────────┴──────────────────────────────────────────────┘
```

### 1.1 设置导航按钮

稳定存在的导航项：

- 返回工作区。
- 基础设置：`常规`、`外观`、`模型设置`、`浏览器`。
- Agent 能力：`记忆`、`子智能体`、`插件`、`MCP 服务器`、`技能`、`命令`、`钩子`。
- 数据与统计：`索引库`、`使用统计`、`引导`。

导航项是紧凑的整行按钮。当前页面使用 selected 背景和高对比文字，分组标题使用更弱的辅助颜色。底部仍有连接使用和帮助入口。

### 1.2 设置页通用布局

大多数页面采用：

1. 内容区顶部页面标题。
2. 一句较弱的说明或帮助文本。
3. 一个或多个 section 标题。
4. 深色 settings card。
5. card 内的行：左侧标题和描述，右侧控制。

通用行约束：

- 左侧标题是主文本，说明是次文本。
- 右侧控件使用固定最小宽度，避免不同状态改变整行宽度。
- 开关靠右对齐，按钮/选择器位于同一基线。
- 独立危险操作使用红色按钮，但仍放在正常的信息层级中。
- 多行说明允许换行，不能压缩到按钮下方形成重叠。
- 页面内容宽度约 800 px，过长页面仅内容列滚动。

## 2. 常规

常规页是长表单型设置页，信息密度最高。主要 section 和控件如下：

| Section/主题 | 控件 | 说明 |
| --- | --- | --- |
| 语言 | 界面语言选择器 | 与左下角界面语言入口保持同一设置 |
| 终端 | 终端配置选择器 | 选择默认 shell/profile |
| 终端字体 | 字体或字号控制 | 影响终端和代码输出可读性 |
| 网络 | 代理配置 | 输入代理地址或选择系统代理 |
| 证书 | 证书校验开关/配置 | 与浏览器安全设置区分 |
| 性能 | 硬件加速开关 | 可能需要重启提示 |
| 更新 | 自动更新或检查更新按钮 | 低频操作，放在辅助 section |
| 通知 | 通知开关 | 控制任务完成、失败等提醒 |
| 工作状态 | 保持唤醒开关 | 运行长任务时避免系统休眠 |
| 交互 | 任务结束后的行为 | 例如自动聚焦、打开结果等 |
| 消息流 | 消息显示行为 | 例如工具过程、思考过程的默认展示 |
| 任务 | 归档行为 | 自动归档或手动归档 |
| 存储 | 数据/工作区路径 | 路径输入或打开目录按钮 |
| 引导 | 重新打开首次启动引导 | 导航或按钮 |
| 体验 | 优化体验开关 | 数据收集或反馈偏好 |

常规页应使用多个 section 分隔，而不是一张无限长卡片。长页面滚动时，页面标题不必固定，但左侧设置导航保持可见。

## 3. 外观

外观页聚合用户可直接感知的视觉参数：

### 3.1 顶部控制

- `界面主题`：主题选择器或 segmented control。
- `界面字体大小`：步进器、选择器或字号菜单。

### 3.2 代码显示

- 代码主题选择器。
- 显示行号开关。
- 代码换行开关。
- 代码字体大小步进器/选择器。

### 3.3 预览

页面下方有浅色/深色代码或界面预览，并标记当前 active 方案。预览是设置的反馈，不是可交互的装饰图片；选中主题应能在预览中体现边框、背景、文字和代码色彩的变化。

## 4. 模型设置

模型设置使用 master-detail 布局，和普通的单列 settings card 不同：

```text
┌─────────────────────┬───────────────────────────────────┐
│ 模型供应商列表        │ 当前供应商详情                       │
│ BigModel             │ 标题 / 状态                         │
│ 自定义供应商          │ 连接方式选择器                       │
│                     │ 计费/方案卡片                       │
│                     │ 保存、测试连接或管理模型             │
└─────────────────────┴───────────────────────────────────┘
```

左侧是供应商列表，选中项有背景；右侧显示：

- 供应商名称和连接状态。
- 连接方式。
- 账单、套餐或用量信息。
- 当前供应商支持的模型。
- 管理或添加自定义模型的动作。

此页的关键学习点是“列表选择影响右侧详情”，不要把每个供应商都堆成同级卡片。

## 5. 浏览器

观察到的页面包含三个 section，均为卡片行布局。

### 5.1 浏览器控制

| 控件 | 类型 | 当前观察 |
| --- | --- | --- |
| 开启内置浏览器控制 | switch | 开启 |

右侧开关，左侧标题和说明。说明强调内置浏览器控制能力。

### 5.2 安全

| 控件 | 类型 | 当前观察 |
| --- | --- | --- |
| 忽略证书校验 | switch | 关闭 |

这是安全敏感开关，开启时需要清晰的风险说明；不能只用普通成功色表示。

### 5.3 浏览器数据

| 行 | 左侧说明 | 右侧按钮 |
| --- | --- | --- |
| 导入 Chrome 浏览器数据 | 导入已有浏览器设置或数据 | `导入浏览器数据` |
| 清除内置浏览器缓存 | 清除缓存 | `清除缓存`，无可清理内容时可 disabled |
| 清除全部浏览器数据 | 清理全部数据 | `清除全部`，红色危险按钮 |

危险操作使用独立确认流程，不应因点击行本身立即执行。

## 6. 记忆

记忆页管理 workspace memory：

- `启用工作区记忆` switch。
- 工作区选择器。
- 记忆文件数量/状态。
- 搜索记忆文件输入框。
- 记忆文件列表。
- 每行的文件名、摘要、更新时间或来源。
- `在 Finder 中打开` 或类似打开方法。

开关影响整个工作区，工作区选择器影响下面的文件范围。搜索只过滤列表，不应改变当前工作区。

## 7. 子智能体

子智能体页面是设置区中信息密度较高的列表页。

### 7.1 顶部工具行

- 用户范围 popover，当前显示 `用户`。
- 计数文字，如 `子智能体 5`。
- `搜索子智能体...` 搜索框。
- `刷新` 图标按钮。
- `新建` 按钮。

### 7.2 已安装列表

section 标题为 `已安装 3 项`。暗色列表卡片包含三行：

- `subagent-glm`，模型标签 `glm-5.3`，工具标签 `全部工具`，启用 switch，删除图标按钮。
- `subagent-gpt`，模型标签 `gpt-5.6-sol`，工具标签 `全部工具`，启用 switch，删除图标按钮。
- `subagent-kimi`，标签 `继承默认` 和 `全部工具`，启用 switch，删除图标按钮。

每行右侧固定为“启用 switch + 删除按钮”，保证名称和描述区不会随操作状态移动。

### 7.3 内置子智能体

section 标题为 `内置子智能体 2 项`。列表行包含：

- `general-purpose`，标签 `全部工具`，右侧 `继承默认` popover。
- `Explore`，标签 `7 个工具`，右侧 `继承默认` popover。

内置项和已安装项的右侧动作不同：前者是继承配置选择，后者是启用/删除。组件可以共享列表行骨架，但不能共享错误的动作语义。

## 8. 插件

插件页顶部有 tabs：

- `插件 7`
- `MCP 4`
- `技能 14`

当前 tab 下通常有搜索框、安装/浏览入口和列表。

已安装为空时显示空状态：说明当前没有已安装内容，并提供 `浏览插件` 按钮。内置或可用列表行包含：

- 插件图标。
- 名称和描述。
- 更多按钮。
- 启用 switch。

tabs 上的数量是信息摘要，不是按钮状态；当前项仍需要 selected indicator。

## 9. MCP 服务器

页面使用与子智能体类似的资源列表结构：

- 用户范围 popover。
- `MCP 服务器` 数量。
- 搜索框。
- 已安装服务器列表。
- 新建/刷新或更多操作。

服务器行显示：

- 服务器名称。
- transport 类型或命令。
- 命令摘要。
- 开关状态。
- 删除/编辑/更多按钮。

插件提供的服务器可以出现在单独 section，和用户安装项分开，避免用户误以为可以直接修改插件内置定义。

## 10. 技能

技能页仍采用“范围 + 计数 + 搜索 + 分组列表”的结构：

- 顶部用户 popover。
- 技能数量。
- 搜索技能输入框。
- 已安装技能行。
- 分组：`Browser Use`、`Document Skills`、`Skill Creator`、`ZCode Guide`。

每个技能行可包含图标、名称、描述、启用 switch 和更多按钮。分组标题用于扫描，不要做成额外嵌套卡片。

## 11. 命令

命令页的工具栏包含：

- 用户范围 popover。
- `命令` 数量。
- 搜索框。
- `刷新`。
- `新建`。
- 更多按钮。

列表行显示命令名称、来源/描述和启用 switch。命令属于可调用能力，默认状态应让用户知道是否启用；`/` Composer 菜单应与此页共享命令名称和状态。

## 12. 钩子

钩子页是“资源列表 + 空状态”模式：

- 用户范围 popover。
- `钩子` 数量。
- 搜索钩子输入框。
- `刷新`、`新建钩子`。
- 已安装钩子列表，或空状态。

空状态不能只写“暂无数据”，应提供唯一的下一步按钮 `新建钩子`。危险删除、禁用和编辑放到每行更多菜单或右侧动作组。

## 13. 索引库

观察到的索引库页标题为 `索引库`，section 为 `代码库`，卡片内有两行：

| 控件 | 说明 | 类型 | 当前观察 |
| --- | --- | --- | --- |
| 索引新文件夹 | 自动索引文件数少于 50,000 的新文件夹 | switch | 关闭 |
| 索引存储库以实现即时搜索（测试版） | 自动索引仓库以加快 Grep 搜索；数据本地存储 | switch | 关闭 |

说明文字较长，右侧 switch 仍固定在行末，左侧内容允许自然换行。测试版能力应该在标题中标记，而不是用额外的彩色徽章制造噪声。

## 14. 使用统计

使用统计不是普通设置表单，而是数据仪表板：

### 14.1 KPI 条

顶部显示应用用量摘要，使用多个水平 KPI 单元：

- 时间范围或累计范围。
- Token 用量。
- 请求/任务数量。
- 可能的模型或连接摘要。

KPI 单元需要稳定宽度、主数值和弱标签，不能让长数字改变整条布局。

### 14.2 Token 活动

页面主体有 `Token 活动` 热力图或活动格：

- 视图切换：`每日`、`每周`、`累计`。
- 色阶表示使用密度。
- 需要图例或辅助说明。

### 14.3 趋势图

有时间范围 tabs：`近 7 日`、`近 30 日`，以及按模型区分的折线趋势图。图表下方或旁侧显示模型图例。空数据时需要空状态，不应画出误导性的零线。

## 15. 引导

引导页本身是设置导航的一部分，但采样时打开的是一个首次启动 modal，覆盖在设置 Shell 上：

```text
暗化 + 模糊的设置背景
┌────────────────────────────────────────────────────────┐
│ [首次启动设置]                                  [×]   │
│ ZCode 图标                                             │
│ 欢迎使用 ZCode                                         │
│                                                        │
│ [开始使用 ZCode                         →]             │
│ [数据迁移向导                           →]             │
│                                                        │
│ 可立即导入旧工具设置，或先跳过，稍后在设置中继续迁移。    │
│                                      ┌───────────────┐ │
│                                      │ 快速打开，      │ │
│                                      │ 专注工作。      │ │
│                                      │ 说明文字        │ │
│                                      └───────────────┘ │
└────────────────────────────────────────────────────────┘
```

观察到的控件：

- `开始使用 ZCode`：主按钮，白色高对比，右侧箭头。
- `数据迁移向导`：次按钮，深色透明/边框样式，右侧箭头。
- `Close`：右上角关闭图标按钮。
- 左侧小标签 `首次启动设置`。
- 右侧是蓝色视觉预览区域和引导文案。

模态打开后，底层设置页面仍可辨认但不能交互。它与全局搜索的区别是：引导用于一次性决策，拥有更大的内容面积、说明文案和明确的主次按钮。

## 16. 设置页按钮分类

| 类别 | 示例 | 反馈方式 |
| --- | --- | --- |
| 导航 | 返回工作区、设置导航项 | 页面切换、selected |
| 选择 | 主题、模型、供应商、语言 | popover、check |
| 二元设置 | 启用浏览器、索引、记忆、开关 | switch、状态文本 |
| 创建 | 新建、导入、浏览插件、新建钩子 | 主/次按钮 |
| 管理 | 刷新、更多、删除、编辑 | 图标按钮或菜单 |
| 危险 | 清除全部、删除 | 红色、确认 modal |
| 数据反馈 | 使用统计 tabs、图表范围 | segmented/tab selected |

## 17. 设置区复刻验收清单

- [ ] 所有设置页共用标题、section、card row 骨架。
- [ ] 设置导航固定，内容列独立滚动。
- [ ] switch、popover、按钮和输入框的右侧对齐线稳定。
- [ ] 模型设置使用 master-detail，而不是普通单列列表。
- [ ] 插件/MCP/技能/命令/钩子都支持范围、搜索、计数和空状态逻辑。
- [ ] 浏览器页区分普通开关、安全开关、导入按钮和危险按钮。
- [ ] 索引库长说明换行时不会撞到右侧 switch。
- [ ] 使用统计的 KPI、热力图和折线图拥有独立的视觉层级。
- [ ] 引导 modal 有遮罩、关闭按钮、主次动作和迁移入口。
