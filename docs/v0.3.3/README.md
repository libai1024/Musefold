v0.3.3 把对话界面右上角的 Ember 圆点升级为**全局品牌构件「朱点」**：它同时是运行状态的呼吸灯、随手速记的入口（笺匣体系）和首启「引首落印」仪式的主角。核心新规是**全局存在性**——所有页面必须为朱点让出固定位置，确保用户在任何页面都能一步完成记录。

## 已确认的产品决策

- 朱点是全应用**单实例**：挂载在内容视口（AppShell `<main>`）右上角，切换页面时原位不动。
- 所有页面必须让出朱点保留区；保留区内不得放置任何可交互元素。
- 隐喻体系从「种子」全面替换为**文房朱砂**：圈点（状态）、批注（速记反馈）、钤印（开卷仪式）。
- 捕捉路径三条并存：**拾选**（选中内容后单击朱点）、**素笺卡**（双击）、**拾遗**（Alt+双击即抓剪贴板）。
- 选区含图片时默认取**第一张图**入笺。
- 速记产物是提示词库中的「笺」（`source: 'slip'`），统一入「笺匣」视图；**誊清**后翻转为正式提示词并离开笺匣（inbox zero）。
- 首启引导完成后路由改为**工作台（generate）**，并播放一次「引首落印」；跳过引导不播放；重看引导后再次完成会重播。
- 落印后浮现的一行小字定稿为：**「引首一点朱」**。
- 无选区时的单击保持纯触感动画，作为未来功能（完成待看 / 活动中心）的保留插槽。
