# v0.3.3 朱点（Ember Mark）UI 与交互规范

> 状态：已确认，本文档是朱点体系的 UI 事实源
> 前置：`docs/v0.3/MUSEFOLD-BRAND-PLAN.md`（Graphite / Ember 纪律）、`docs/v0.3.2/`（方案与运行时语义）
> 实现基线：`src/features/generation/workbench/EmberStatusDot.tsx`（v0.3.2 已实现的印泥质感圆点，本版本升级为全局构件）

## 0. 一句话定位

朱点是 Musefold 的**案头朱砂**：平时安静地坐在卷面（内容区）右上角作为引首印；生图 / Agent 运行时以墨洇呼吸表达"正在发生"；用户随手**圈点、记笺、拾遗**，把未成形的念头收进笺匣。

隐喻词汇表（UI 文案必须使用左列词汇，不再使用"种子"体系）：

| 概念 | 词汇 | 出处 |
|---|---|---|
| 圆点本体 | 朱点 | 朱笔圈点，"可圈可点" |
| 首启仪式 | 引首落印 | 书画引首印位于卷首右上 |
| 落印小字 | 「引首一点朱」 | 本版本定稿文案 |
| 速记小卡 | 素笺 | 文人便笺；顶部红栏为朱丝栏 |
| 剪贴板预填 | 拾得 | 拾遗掇拾 |
| 选中即收 | 拾选 | 同上 |
| 剪贴板即抓 | 拾遗 | 同上 |
| 收纳视图 | 笺匣 | Zettelkasten 的字面义 |
| 草稿转正 | 誊清 | 草笺誊为定稿 |

## 1. 全局存在性（本版本核心新规）

### 1.1 挂载与唯一性

- 朱点是**全应用单实例**，从 `GenerationWorkbench` 上移至 AppShell 内容视口：

```163:164:src/components/layout/AppShell.tsx
            <main className="relative min-h-0 flex-1 overflow-hidden bg-elevated">
              {children}
```

- 挂载为 `<main>` 的直接子元素，绝对定位 `top: 20px; right: 20px`（与上、右边界**严格等距**），z-index 位于页面内容之上、弹层（popover/dialog/toast）之下。
- 切换页面时朱点**原位不动、不重挂载**——它是桌上的镇纸，页面在它下面翻动。状态（呼吸、批注、素笺卡开合）跨页面连续。
- 引导页（onboarding，`z-[200]` 全屏覆盖）期间朱点不可见；首次出现即「引首落印」仪式（§7）。

### 1.2 朱点保留区（所有页面必须遵守）

- 保留区定义：内容视口右上角 **64 × 56 px**（朱点 40px 热区 + 呼吸光晕与空气）。
- **保留区内不得放置任何可交互元素**；纯装饰或滚动内容可以从其下方穿过（朱点悬浮其上）。
- 各页面让位审计与整改要求：

| 页面 | 现状 | 整改 |
|---|---|---|
| 工作台 generate | 已就位（v0.3.2） | 挂载点上移后删除页内实例 |
| 提示词库 library | 顶部工具栏靠右有图标动作 | 工具栏右端预留 `padding-right ≥ 64px`，或工具栏整体下移至保留区之下 |
| 生成历史 history | 顶部筛选行靠右 | 同上 |
| 设计方案 schemes | 目录页右上有主操作按钮 | 主操作按钮内收，与保留区间距 ≥ 8px |
| 设置 settings | 内容窄栏（max-w 680）居中，宽窗无冲突 | 窗口 < 960px 时分区头部 action 行追加 `padding-right`，避让保留区 |
| 引导 onboarding | 全屏覆盖层 | 不放朱点；完成时执行落印 |

- 验收方式：每页在 1440 / 960 / 720 三档宽度下截图，保留区内命中测试（elementFromPoint）不得返回页面级可交互元素。

### 1.3 与滚动、抽屉的关系

- 朱点不随内容滚动（相对内容视口固定）。
- 右侧抽屉（参考图侧栏等）打开时朱点浮于抽屉之上，不移位、不隐藏。
- 全屏灯箱 / 模态打开时朱点被遮蔽属于预期（弹层 z 更高），关闭后原位复现。

## 2. 视觉与状态语义

### 2.1 视觉（沿用 v0.3.2 已实现的印泥质感）

- 核心 15px、热区 40px；`.ember-seal` 材质：哑光、中心颜料略薄、边缘积墨、细颗粒纸纹、0.5px 沉边、轻浮起投影。
- 颜色唯一来源 `var(--accent)`（浅 `#D6653F` / 深 `#EF7A52`），与 logo 灵感种子点同源。
- 深色主题空闲态**无环境光**（品牌纪律：只有正在发生的动作被点亮）；悬停允许一丝余温投影。

### 2.2 状态表

| 状态 | 判定 | 表现 |
|---|---|---|
| 空闲 | 无任务 | 静止朱点 |
| 运行 | `isGenerating` ∨ 任一会话 `latestStatus==='running'` ∨ Skill `detecting/executing` ∨ 方案运行 `running` | 墨洇呼吸：模糊光晕 2.2s 起伏（`ember-breathe`） |
| 批注 | 拾选 / 拾遗刚完成 | 点旁浮现一行批注 2s（§6） |
| 落印 | 首启仪式 | §7 |

- 减少动效（显式开启或跟随系统）：呼吸冻结为静态柔光，批注照常显示（信息非动效）。
- 状态经 `data-state="idle|busy"` 暴露给测试。

## 3. 交互矩阵（本版本定稿）

| 手势 | 条件 | 行为 | 触感动画 |
|---|---|---|---|
| 悬停 | — | 无功能 | 微亮 + 投影加深（余温） |
| 单击 | **存在页面选区** | **拾选**：选区 → 笺（§4） | 按压缩回 + 单圈墨晕 |
| 单击 | 无选区 | 无功能（未来功能插槽） | 同上，纯触感 |
| 双击 | — | **素笺卡**开合（§5） | 果冻挤压 + 双圈墨晕 |
| Alt + 双击 | — | **拾遗**：剪贴板 → 笺（§6） | 吞咽挤压 |
| Esc | 素笺卡开启时 | 关卡 | 卡散去 |
| Tab / Enter | 键盘 | 聚焦朱点；Enter 等价单击 | 同单击 |

- 预留：`⌘⇧J`（记一笔）全局快捷键位，本版本不实现。
- 冲突消解：双击必然先触发一次单击——若单击命中拾选，300ms 内跟随的双击**取消该次拾选**并改开素笺卡（选区内容转为素笺卡预填），避免双收。

## 4. 拾选（选中内容 → 笺）

**流程**：用户在应用内任意页面选中内容 → 单击朱点 → 内容直接成笺入匣 → 批注浮现（§6 统一反馈）。

- **选区来源**：`window.getSelection()` 的页面静态内容选区。**输入框/文本域内的选区不算**（用户正在编辑的内容不拾），Composer 草稿除外场景一律排除。
- **文字**：`selection.toString()`，收前做 trim；超过 2000 字截断并追加省略号（笺是念头不是文档）。
- **图片**：`range.cloneContents()` 中查询 `<img>`；**默认取第一张**，其余忽略。图片 `src` 反解为应用管理的本地路径（`toImageSrc` 的逆映射），写入笺的 `previewImagePath`；非应用资源（外链）忽略图片只收文字。
- **文字 + 图共存**：允许，同入一笺。
- **保持选区**：朱点在 `pointerdown` 阶段 `preventDefault()`，避免点击行为清除页面选区。
- **空选区**：不可能进入本路径（无选区单击 = 触感插槽）。
- **误拾兜底**：批注即撤销（§6）。

## 5. 素笺卡（双击）

```
双击朱点 → 点下方右对齐滑出素笺（约 288×288 方形笺面）：
┌──────────────────────────────┐
│ ⌐ 素笺              9      × │ ← 笺头：未像小印 + 题名 + 字数（有字才现）+ 手动关闭
│  记一笔…                       │ ← 多行落笔处，朱丝横格铺底，自动聚焦
│  ＿＿＿＿＿＿＿＿＿＿＿＿＿＿   │    （Enter 收下，Shift+Enter 换行，IME 组字安全）
│  〔拾得 · "剪贴板前 24 字…" ×〕   │ ← 剪贴板文字预填块，可整块剔除
│  ⌘V 可贴一张图        （折角）│ ← 空态提示；右下角翻起页角是「未像」签名
└──────────────────────────────┘
Enter = 收入笺匣 · Esc / 笺头 × = 散去
点卡外仅在「空笺」时散去；已有任何内容（手打 / 拾得 / 图）必须 Esc 或 ×，防误失
```

- **纸的质感**：暖纸底（elevated 基础上加一丝暖）、复用朱点的噪声纸纹、朱丝栏一线；无大阴影。
- **预填规则**：打开时静默 `readText()`；有内容显示为「拾得」块而非直接灌入输入框（主动权在人）。图片仅接受粘贴（⌘V），复用 Composer 现有粘贴管线。
- **组合**：手打文字、拾得块、贴图可任意共存，同入一笺。
- **收下动效**：笺片轻轻一折、斜滑入朱点后方（纸的动效，不缩成粒子）；朱点微沉一次。**不弹 toast**。
- **空笺 Enter**：卡横向轻摇 2px，不落库。
- **再次双击**：空笺时双击 = 关卡；已有内容时双击不关（与外点同属误触路径），需 Esc 或 ×。
- 减少动效：滑出/折入替换为淡入淡出。

## 6. 拾遗（Alt+双击）与批注反馈（统一规范）

**拾遗**：Alt+双击 → 立即读剪贴板（文字或图）→ 直接成笺 → 批注浮现。空剪贴板批注「剪贴板无物」，不落库。

**批注**（拾选与拾遗共用的确认 + 撤销通道）：

- 形态：朱点左侧浮现一行小字，如 `拾得 ·"暮色里的旧书店，暖…"已入匣`，停留 2 秒后散去。
- **批注本身是撤销键**：停留期内点击批注 = 抽回该笺（删除刚落库的记录），批注文案变为「已抽回」随即散去。
- 入库策略：**立即入库**，撤销走删除（复用软删除基建）。
- 无障碍：批注容器 `role="status"`（读屏播报），撤销可 Tab 聚焦。

## 7. 引首落印（首启仪式）

**触发**：引导流程 `finish()`（完成第 4 步）。跳过（skip）不播放；设置中重看引导后再次完成会重播。**路由变更：`finish()` 进入工作台（generate），不再进入提示词库**（skip 仍进提示词库，既有行为不变）。

**时序（总长约 1.1s）**：

| 时间 | 画面 |
|---|---|
| 0ms | 捕获引导页内 logo `[data-logo-dot]` 屏幕坐标；引导页卸载，工作台显现，朱点本体隐藏 |
| 0–900ms | 覆盖层朱点从 logo 位置以**运笔的弧**（慢起、平滑、收势，非弹跳）飞向保留区落点，尺寸渐变至 15px |
| 900–1100ms | **钤印按压**：落点轻微下压放大（印章吃纸），一圈墨晕荡开收净；本体显形 |
| 1100ms 起 | 点旁浮现小字**「引首一点朱」**，约 2.6s 后散去 |

- 任意点击跳到终态；窗口 resize 中断动画直接落位。
- 减少动效：整段跳过，朱点直接在位，小字照常浮现一次。
- 实现要点：瞬态 store 传递起点坐标（`phase: idle→flying→landing→idle`）；飞行覆盖层挂 App 层；落地动画由朱点本体执行，交接帧同位同尺寸。

## 8. 笺匣（提示词库）

- `PromptSource` 增加 `'slip'`；笺 = `Prompt{ content: 文字, previewImagePath: 图, title: 内容前 12 字（纯图笺为「图像一笺」）, source: 'slip' }`。
- 提示词库顶部增加「笺匣」筛选 chip：`source==='slip'`，有笺时显示数量。
- 空态文案：**「匣中无笺。任何页面双击右上角的朱点，随手记一笔。」**
- 笺行动作：**誊清**（打开现有编辑器补全，保存时 `source → 'manual'`，离开笺匣进入正式库）、**引用**（作为胶囊插入当前对话，复用 `draftReferences`）、删除。
- 笺匣是收件箱不是仓库：誊清即出匣（inbox zero）。

## 9. 数据与技术要点

| 项 | 决定 |
|---|---|
| 数据模型 | 不建新表；`PromptSource` 加 `'slip'`（enums + DB 校验 + 仓储层放行） |
| 图片入笺 | 拾选反解应用内路径；素笺卡贴图复用 Composer 图片粘贴/存储管线 |
| 全局状态源 | 呼吸判定聚合 workbench / skillRuntime / schemeRun 三个 store（已实现），上移后逻辑不变 |
| 动效 | CSS（呼吸/批注淡入）+ GSAP（触感/落印/折入），沿用 `MusefoldLogoAnimated` 的减少动效门控模式 |
| 单实例迁移 | `EmberStatusDot` 从工作台移至 AppShell；工作台内不再渲染 |
