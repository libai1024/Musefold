# UI 审计:应用壳(AppShell / 侧栏 / 账号页脚)

> 只读审议(代码 + 既有截图),不改代码。基线:`b121303` 之后的工作树;截图取 `tests/v25/__screenshots__/web-desktop/`。
> 风格基准:2.5.0 设计语言(陶土橙主色、暖灰中性面、8px 控件圆角、细滚动条、极简模型 pill 的「安静默认 + hover 浮出」语法)。

## 总体评价

壳层是最成熟的部分:侧栏密度、导航态(`aria-current` + `sidebar-accent` 面)、账号页脚的「身份 + 积分 + 设置齿轮」三段式都稳定,视觉噪音低。问题集中在**图标语义缺失**与**个别强制文字钮**。

## 发现

### S1(中)账号页脚「登录账号 / 同步与云生图」双行文字常驻
- 位置:`packages/features/src/account/AccountFooter.tsx:259-264`(`trigger.title` 由 `signedIn` 分叉)。
- 现象:未登录时页脚是一块两行文字按钮「登录账号 / 同步与云生图」;登录后变成「用户名 / 积分」。信息双行可以理解,但**未登录态的两个短语本质是同一动作的重复说明**,占位显著且与上方「新设计」行的排版语法不一致。
- 建议:未登录收敛为单行「登录账号」+ 行尾 `arrow-right-to-line` 小图标;「同步与云生图」降为 title 提示。已登录态保持现状(用户名/积分是真实信息)。

### S2(低)「新设计」行的 ⌘N 角标在窄侧栏没有降级
- 位置:`SessionListPanel.tsx` `NewSessionAction`(`Kbd` 右列)。
- 现象:侧栏可拖到较窄宽度,`Ctrl+N` 角标挤占标题空间;截图 `prompts-list.png` 里 `N` 已被裁掉一半。
- 建议:低于阈值(如 < 220px)隐藏 Kbd,保留 title。

### S3(低)侧栏收起/展开的 tooltip 已实装但拖宽手柄无任何提示
- 位置:`AppShell.tsx:367`(`aria-label="调整侧栏宽度"`)。
- 现象:手柄 8px 骑缝命中区 hover 只变背景,无 tooltip 也无光标变化提示可拖;与「收起/展开都有 tooltip」的新语法不一致。
- 建议:`cursor-col-resize` + title「拖动调整宽度」。

### S4(低)对话列表空态文案过长
- 截图:`prompts-list.png` 左栏「还没有对话。点「新设计」开始,发送后会立即出现在这里。」折三行。
- 建议:收敛为「点「新设计」开始」+ 省略剩余说明(或仅保留第一句)。

### S5(信息)品牌行收起钮已带 tooltip,行为一致
- `AppShell.tsx:93`,本次走查已修,无新问题。记录为「已达标」样例。
