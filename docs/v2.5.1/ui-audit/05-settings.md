# UI 审计:设置(分区导航 / 外观 / 账号 / AI 连接 / 数据 / 关于)

> 只读审议。截图:`settings-light.png`、`settings-signed-in.png`、`settings-login-devices.png`、`settings-dark.png`,以及 Windows 真机流程 `05-07`(AI 连接)。代码:`SettingsScreen.tsx`、`sections.tsx`、各 Card、`LoginSessions.tsx`、`AccountPanel.tsx`、`AccountCloudConnectionCard.tsx`。

## 总体评价

设置页骨架(搜索 + 分区导航 + 卡片流)是全应用最规范的页面;段控件(主题/动效/密度)、行式表单节奏统一。问题集中在**登录设备工具条的按钮形态**、**账号卡的危险动作层级**、**云连接卡的文字密度**。

## 发现

### T1(高)登录设备工具条三枚 outline/default 文字钮平铺,危险度无分层
- 位置:`LoginSessions.tsx:576-610`。现状:「刷新」「退出此设备」outline + 「释放所选」default(主色)平铺一行;截图 `settings-login-devices.png` 中「释放所选」呈橙色实心,视觉地位反而高于破坏性的「退出此设备」。
- 问题:①「刷新」是高频小动作,不该与危险动作同占一行三席位——应 icon 化(`refresh-cw`)收进行尾;②「退出此设备」是破坏动作,应是 destructive ghost/outline;③「释放所选」依赖复选框选择,主色实心合理,但在无选中时禁用态也占据主位。
- 建议:`[icon 刷新] …spacer… [退出此设备(outline)] [释放所选(primary,选中≥1 才亮)]`,危险动作靠右,符合「主动作右置、破坏动作降级」惯例。

### T2(中)账号卡动作排布:「兑换码」输入行与「验证另一台设备」区块并列,层级平
- 截图:`settings-signed-in.png`。账号卡内从上到下:身份行 → 兑换码 → 「验证另一台设备」说明+输入 → 「退出登录」(右下 ghost)。
- 问题:①「验证另一台设备」整段(标题+两行说明+输入+按钮)在**未发起恢复时**也全量展开,占据卡片一半——低频流程常驻;②「退出登录」是文字 ghost 钮沉在右下角,破坏性动作没有分隔(与上方内容之间只有空隙,无 Separator/降级区)。
- 建议:恢复流程折叠为一行入口「验证另一台设备 ›」点击展开;「退出登录」上移至身份行行尾(icon `log-out`,title 保留文字)并加确认(已有 AlertDialog)。

### T3(中)云连接卡文字密度过高
- 截图:`07-cloud-connected.png`(Windows 真机)。「账号云图像」卡:标题+两行描述+两行状态说明+账号/origin 行+两枚按钮;三段灰字连排。
- 建议:状态改图标化状态行(✓ 已连接 · xiaomiao · zhaozhaoyue.top),按钮行保留「检查连接」ghost + 「当前默认连接」禁用态;描述里「连接与云同步分别设置」收进 title 或帮助图标。

### T4(中)AI 连接卡「本地生图服务连接…密钥保存在系统安全存储」与 Agent 卡描述几乎双写
- 截图:`07-cloud-connected.png` 下部两卡:「AI 连接」与「Agent 连接」标题+描述+「尚未配置…新建一个以启用…」+ 两枚 preset 钮(TvT AI 中转站/自定义;DeepSeek/Kimi/GLM)。两卡结构重复且 preset 按钮组各不相同,首屏信息量大。
- 建议:统一「空态一行 + 新建(内含 preset 选择)」结构;preset 钮收进新建 Dialog 的模板选择,卡片只留「+ 新建」。

### T5(低)分区导航「访问」组的「账号 / 云同步 / AI 连接」与「应用」组的「数据 / 开放能力」命名粒度不一
- 截图:`settings-light.png`。通用(1 项)/访问(3 项)/应用(2+ 项)分组存在,但「关于」「使用统计」归属在截图里不可见分组(关于在最后)。分组名与内容映射基本合理,仅「开放能力」偏产品词汇。
- 建议:保持;若后续加分区,注意每组 ≥2 项的视觉平衡。

### T6(低)外观卡的段控件(跟随系统/浅色/深色 等)是全应用唯一的分段控件群,选中态依赖 `--segment-on`
- 截图:`settings-light.png`。浅色下选中面与容器几乎同值(走查已加 `--segment-on` 修正深色);浅色下「跟随系统」选中态仅靠 icon+字重区分,偏弱。
- 建议:浅色选中面加 1px `--border` 或轻阴影,提升可辨性。

### T7(信息)右侧「Web 版 / 桌面版」Badge
- 截图右上角常驻宿主徽标。信息价值低(用户知道自己在哪),但用于双宿主支持判定截图,保留;建议 future:仅在非默认宿主显示。
