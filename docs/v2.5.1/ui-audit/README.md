## 共性主题(跨页反复出现)

1. **「刷新」类动作形态不统一**:方案列表已 icon 化;登录设备/公告/云恢复仍是文字钮 → 统一 icon + title。
2. **Tabs 语法分叉**:提示词库纯文字 vs 生成历史带 icon → 择一全局统一。
3. **文字动作钮是最后的异类**:模型 pill 已示范「安静默认」,剩余的文字钮(使用/释放所选/跳过引导/登录账号)应逐个判断「icon 化 or 降级为链」,消灭与图标组并排的混排。
4. **破坏性/低频动作缺层级**:退出登录、退出此设备、跳过引导都以常规面积出现 → 按方位差+降级语法处理。
